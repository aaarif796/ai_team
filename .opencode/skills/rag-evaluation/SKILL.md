# Rag Evaluation

## Purpose
Evaluate retrieval, generation and complete RAG behavior separately.

## Procedure
Build query/reference sets; score retrieval ranking and context quality; evaluate faithfulness, relevancy, correctness, citation support, latency and cost; inspect per-query failures.

- State the work performed and the evidence used.
- List files, commands, versions and results where applicable.
- Identify assumptions, limitations and unresolved questions.
- Recommend the next step without claiming it has been completed.
