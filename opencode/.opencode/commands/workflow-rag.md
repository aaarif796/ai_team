description: Design, build, or evaluate a RAG pipeline.
agent: sdlc-orchestrator
---

Coordinate a RAG workflow:
1. Define corpus, user queries, expected answers, constraints, and acceptance metrics.
2. Inspect ingestion, parsing, chunking, metadata, embeddings, index, retrieval, reranking, and generation.
3. Build a representative evaluation dataset.
4. Evaluate retrieval (for example context precision/recall) separately from answer quality
   (for example faithfulness and answer relevance).
5. Diagnose failure categories and change one major variable at a time.
6. Re-run evaluations and report metric deltas, limitations, and cost/latency.
