---
description: Reproduce, diagnose, fix, and regression-test a bug.
agent: sdlc-orchestrator
---

Fix the reported bug with evidence:
1. Inspect relevant code, logs, and existing tests.
2. Reproduce the issue or clearly state why reproduction is unavailable.
3. Create a failing regression test before the fix when practical.
4. Identify root cause; do not patch symptoms without explanation.
5. Implement the smallest safe fix.
6. Run the regression test and relevant surrounding tests.
7. Review for side effects and summarize evidence and remaining uncertainty.
