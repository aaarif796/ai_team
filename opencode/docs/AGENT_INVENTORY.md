# Agent inventory

- **sdlc-orchestrator** — Coordinates end-to-end SDLC work, chooses specialists, tracks decisions, and validates completion. (default tier: High)
- **requirements-validator** — Clarifies requirements, constraints, edge cases, and measurable acceptance criteria. (default tier: Small)
- **project-planner** — Breaks work into milestones, tasks, dependencies, and deliverables. (default tier: Small)
- **solution-architect** — Designs system boundaries, interfaces, data flows, and architecture trade-offs. (default tier: High)
- **technology-selector** — Compares technology choices against requirements, team constraints, and operational needs. (default tier: High)
- **developer** — Implements scoped changes with maintainable code and focused diffs. (default tier: Mid)
- **tdd-agent** — Creates tests before implementation and guides red-green-refactor cycles. (default tier: Mid)
- **test-engineer** — Designs and executes unit, integration, system, regression, and acceptance tests. (default tier: Mid)
- **qa-automation** — Builds reliable automated test suites and CI test workflows. (default tier: Mid)
- **debugging-agent** — Reproduces failures, isolates root causes, and validates fixes. (default tier: High)
- **code-reviewer** — Reviews code for correctness, maintainability, performance, and regressions. (default tier: High)
- **security-reviewer** — Checks threat surfaces, secrets, auth, input validation, and dependency risks. (default tier: High)
- **performance-engineer** — Profiles bottlenecks and proposes measurable performance improvements. (default tier: High)
- **database-engineer** — Designs schemas, indexes, migrations, transactions, and data access. (default tier: Mid)
- **api-engineer** — Designs and implements APIs, contracts, validation, and error handling. (default tier: Mid)
- **devops-engineer** — Builds CI/CD, container, infrastructure, and deployment configuration. (default tier: Mid)
- **documentation-agent** — Creates accurate developer documentation, runbooks, and change summaries. (default tier: Small)
- **release-manager** — Prepares release notes, versioning, rollout, rollback, and release checks. (default tier: Mid)
- **python-engineer** — Implements and reviews Python services, libraries, and tooling. (default tier: Mid)
- **backend-engineer** — Builds backend services, business logic, and integrations. (default tier: Mid)
- **frontend-engineer** — Builds accessible and maintainable frontend interfaces. (default tier: Mid)
- **data-engineer** — Builds data ingestion, transformation, validation, and storage pipelines. (default tier: Mid)
- **ml-architect** — Designs machine-learning systems, data strategy, model interfaces, and deployment. (default tier: High)
- **ml-engineer** — Implements training, inference, preprocessing, and ML pipelines. (default tier: Mid)
- **data-scientist** — Performs exploratory analysis, feature analysis, statistical evaluation, and experiments. (default tier: High)
- **model-training-agent** — Plans and implements reproducible model training and fine-tuning. (default tier: High)
- **model-evaluation-agent** — Defines evaluation datasets, metrics, baselines, and model acceptance gates. (default tier: High)
- **model-monitoring-agent** — Designs production monitoring for quality, latency, cost, and drift. (default tier: Mid)
- **model-drift-agent** — Investigates data/concept drift and recommends validated response actions. (default tier: High)
- **rag-architect** — Designs retrieval-augmented generation architecture and retrieval strategy. (default tier: High)
- **rag-engineer** — Implements ingestion, chunking, embeddings, retrieval, reranking, and generation. (default tier: Mid)
- **rag-evaluation-agent** — Evaluates retrieval and answer quality using grounded datasets and metrics. (default tier: High)
- **prompt-engineer** — Develops, versions, and tests prompts and structured-output contracts. (default tier: Mid)
- **llm-evaluation-agent** — Evaluates LLM quality, robustness, safety, latency, and cost. (default tier: High)
- **agent-engineer** — Designs agent tools, handoffs, permissions, and multi-agent workflows. (default tier: High)
- **data-quality-agent** — Validates data completeness, consistency, leakage, and lineage. (default tier: Mid)
- **experiment-tracker** — Maintains experiment metadata, reproducibility notes, and result summaries. (default tier: Small)
- **observability-agent** — Adds logs, metrics, traces, alerts, and operational dashboards. (default tier: Mid)
- **migration-agent** — Plans and validates safe database, API, and application migrations. (default tier: High)
- **incident-responder** — Triage incidents, assess impact, coordinate mitigation, and document learning. (default tier: High)
- **accessibility-reviewer** — Reviews interfaces for accessibility and inclusive interaction. (default tier: Mid)
- **dependency-auditor** — Reviews dependency health, licenses, vulnerabilities, and upgrade risk. (default tier: Mid)
- **technical-researcher** — Researches technical options and summarizes evidence with sources. (default tier: High)
- **acceptance-reviewer** — Checks delivered work against acceptance criteria and evidence. (default tier: High)
